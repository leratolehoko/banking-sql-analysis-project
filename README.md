# Banking Database Analysis Project

## Project Overview

The Banking Database Analysis Project demonstrates practical SQL skills through the design, implementation, and analysis of a relational banking database.

The project simulates a real-world banking environment by modelling customers, branches, employees, accounts, transactions, and loans. Using SQL, business questions were answered to generate meaningful insights that support data-driven decision-making.

This project showcases skills in database design, SQL querying, business analysis, and analytical reporting.

---

# Project Objectives

- Design a relational banking database.
- Create relationships using primary and foreign keys.
- Populate the database with realistic sample banking data.
- Analyse banking operations using SQL.
- Apply advanced SQL concepts to answer business questions.
- Present findings and business recommendations.

---

# Database Tables

| Table | Description |
|--------|-------------|
| Customers | Stores customer information. |
| Branches | Stores South African bank branch information. |
| Employees | Stores employee details for each branch. |
| Accounts | Stores customer account information. |
| Transactions | Stores deposits and withdrawals. |
| Loans | Stores customer loan information. |

# Business Questions Answered

1. Top 10 Customers by Total Account Balance
2. Branch with the Highest Total Account Balance
3. Customers with More Than One Account
4. Rank Customers by Total Account Balance
5. Assign a Unique Rank to Customers
6. Running Total of Transactions
7. Running Total of Transactions per Customer
8. Customers Holding Multiple Account Types
9. Branch with the Highest Total Transaction Value
10. Top 5 Customers by Total Transaction Value
11. Month with the Highest Total Transaction Value
12. Loan Distribution by Status
13. Total Loan Amount by Loan Type
14. Customer Distribution by Province
15. Account Distribution by Status

# Key Findings

- Identified high-value customers based on total account balances.
- Determined the highest-performing bank branch.
- Analysed customer account ownership patterns.
- Evaluated transaction activity across different months.
- Analysed loan distribution by type and status.
- Identified opportunities for customer cross-selling and business growth.

---

# Recommendations

- Strengthen customer retention by focusing on high-value customers.
- Encourage customers to open additional banking products.
- Investigate strategies used by high-performing branches.
- Monitor transaction trends for operational planning.
- Improve database design by recording the employee responsible for opening customer accounts.
- Expand the database with additional customer financial information for future analysis.
